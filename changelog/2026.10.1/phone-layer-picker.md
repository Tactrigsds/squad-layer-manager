On a phone, the layer picker is split into Filters, Results and Summary tabs, and opens on Results.

- Search for layers by typing maps, gamemodes, factions, units or filter names into the box above the results, the way `/reqlayer` reads a request. Advanced search edits the same search as a full form, vehicles included.
- Each filter on the Filters tab has an Off, Match or Exclude control.
- Results can be sorted by any visible column, or put in a random order and rerolled with the dice button.
- The indicators beside each result open in a sheet. Each filter listed there has a button that opens the filter.
- The Summary tab lists the selected layers above how they are added to the queue, and holds the Submit button.
- Pickers open as a sheet along the bottom of the screen, with room for the on-screen keyboard.
