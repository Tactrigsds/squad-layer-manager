Squad Layer Manager

SLM is a tool for managing the upcoming layers on a Squad server, and other things also.

Its web app and in-game admin commands simplify layer and player management, and work alongside existing tools such as Discord and BattleMetrics. It is the main admin tool of the TacTrig server.

Setup guideFeaturesDeveloper docs

  • Control over layer selection

    Designed to work in place of the in-game voting system, SLM provides convenient and fine-grained control over what kinds of layers are played on the server.

    Read about layer selection

  • Player management

    Warn, kick and time out players, manage team swaps, and flag and note players through BattleMetrics.

    Read about player management

  • Server monitoring and history

    Follow the live match, chart team balance, scorelines and player population, and search every past event, player and match.

    Read about monitoring and history

  • Extensible with plugins

    Plugins add commands, settings and behaviour. Install one from a URL, or write your own.

    Read about plugins

  • Built to self-host

    Runs on any system with Docker installed.

    Read the install guide

Try it

docker run --rm -p 3000:3000 -e DEMO=1 ghcr.io/tactrigsds/squad-layer-manager:latest
