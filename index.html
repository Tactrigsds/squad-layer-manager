Squad Layer Manager

SLM is a tool for managing upcoming layers on a Squad server, and other things also.

It is the main admin tool of the TacTrig server. Admins use it from a web app that signs in with Discord, and from in-game commands.

Setup guideFeaturesDeveloper docs

  • Control over layer selection

    Filters, repeat rules and a layer pool decide what can be played. SLM warns before a mistake is saved, and warns in-game admins before one is played.

  • Player management

    Warn, kick and time out players, swap them between teams, and take switch requests, from the dashboard or in game. Group players to compare how the teams are made up.

  • Works with your tools

    Users sign in with Discord, and Discord roles grant permissions. Read and set BattleMetrics flags and notes without leaving SLM.

  • Extensible with plugins

    Plugins add commands, settings and behaviour. Install one from a URL, or write your own.

  • Built to self-host

    One Docker image manages all of your servers. SLM backs up its database before each upgrade, and a sandbox server lets you try it without real players.

Try it

Run a demo instance with no authentication:

docker run --rm -p 3000:3000 -e DEMO=1 ghcr.io/tactrigsds/squad-layer-manager:latest
