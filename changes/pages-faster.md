The filter editor, the settings page, the history page and the Add Layers dialog respond faster. A large filter opens without freezing the page, and typing in the filter editor, a role's settings or a history search no longer lags.

Number fields in the filter editor and text fields in the history search are saved a quarter of a second after the last keystroke. A search always uses the latest text.

The layer picker for a "Layer id in" filter starts with an empty filter menu each time it opens. The picker keeps the layers already selected.

BattleMetrics details for a player open at once, even while SLM is refreshing BattleMetrics data in the background. For a player who is offline, the details shown can be up to a few hours old until the refresh finishes.
