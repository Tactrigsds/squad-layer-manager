The layer picker has a search box above the results. Type maps, gamemodes, factions, units or filter names, the way `/reqlayer` reads a request.

The constraint form now opens from the _Advanced_ button beside the search box, and edits the same search. The picker remembers whether _Advanced_ was left open. Submit and the queue options sit along the bottom of the picker.
