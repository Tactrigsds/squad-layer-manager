Buttons that respond to Ctrl+Enter now show the shortcut. On a Mac the shortcut is Cmd+Enter.

Press Ctrl+Enter to run a history query, add a layer note or a BattleMetrics note, or save a tag. In a picker that
selects several options, Ctrl+Enter picks the highlighted option and closes the picker. It no longer runs the history
query behind the picker as well.
