The server console, player details and squad details windows can be maximized to fill the screen. Press the maximize button again to restore the window to its previous size and position.

The activity feeds in the player details and squad details windows can be searched, like the server activity panel and the server console. Press the search button at the top right of a feed, or Ctrl+F after clicking into the feed.

Ctrl+F after clicking into the server console window now opens the console's search instead of the browser's.
