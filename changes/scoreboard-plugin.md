The new Scoreboard plugin posts a scoreboard to a Discord channel when a match ends. It ranks players by kills, revives, vehicle damage, FOB and HAB kills, kill streaks, K/D, deaths and teamkills, ranks squads by kills, and charts each team's kills and tickets over the match.

When SLM runs more than one real server, the scoreboard names its server. The footer shows the match id. Filter the history page by this id to find the match. The plugin ships with SLM and is stopped until an admin starts it under Plugins on the settings page.
