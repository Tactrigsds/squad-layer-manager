Filters and rotations are created and edited the same way. A rotation's name, description and other details are edited in the _Edit Details_ dialog, opened from the pencil beside the name, as a filter's are.

_New Rotation_ now opens a page for the new rotation, where its layers can be added before it is created. The _New Rotation_ dialog opens with the page, and can be closed and opened again from the pencil beside the name. _Create_ saves the rotation with its layers. _New Filter_ works the same way. A new rotation no longer offers to copy another rotation: use _Clone_ on that rotation instead.

A rotation's description is shown as markdown, like a filter's. On a filter, _Apply_ adds the changed details to the filter's draft, and _Save_ on the filter page saves them.
