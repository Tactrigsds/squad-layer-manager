The server dashboard stays responsive on a full server. Kills, chat and BattleMetrics updates no longer redraw every player row, and the dashboard no longer freezes for a moment every few minutes.

SLM opens faster. The first visit downloads about a third less, and pages other than the dashboard are downloaded the first time they are opened. The layer table sorts and filters faster, and a tab left open for days uses less memory.
