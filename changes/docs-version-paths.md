Documentation versions are named like the image tags: `latest`, `stable` and release numbers such as `2026.10.1`. Old
links still open.

The version menu lists the newest release once, as `stable (2026.10.1)`. Each version opens on its own start page. On a
phone, the version menu opens inside the navigation menu, where every version can be picked.
