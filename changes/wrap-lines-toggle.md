Line wrapping can be turned off in the server console, the activity panel, the history page's events, and the
activity feeds of the player and squad details windows. Use the wrap button beside the search button, or in the
toolbar or header above the feed, to turn line wrapping on and off.
With wrapping off, each entry stays on one line. In the console, long lines scroll sideways. In the feeds, a line
too long for the panel is cut short.
